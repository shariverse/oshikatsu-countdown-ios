# このバージョンの新機能（1.3.0）

App Store Connect の「このバージョンの新機能」に入れる文面です（4,000 文字まで）。
ワークフロー「App Store Metadata」が、登録するバージョン（既定は `MARKETING_VERSION`）と同じ名前のファイルを読みます。
見出し（`## <言語>`）はスクリプトが探すので変えません。各見出しの下の最初のコードブロックが登録される文面です。

1.2.0 からの変更は次の 3 つです。

- 推し活カウントダウン Plus（有料）: 推しの写真ウィジェットと、アプリの背景・飾りを推しの写真にする着せ替え。月額・年額（年額は 1 週間の無料のお試し）と買い切り（商品は [in-app-purchases.json](../in-app-purchases.json)）
- 画像でシェア（#218。無料）: 予定の詳細から「あと○日」を正方形のカードの画像にして共有する
- 推しの並べ替えとテーマカラー（#208・#209。無料）: 推しの一覧で並べ替えられ、いちばん上の推しの推し色でアプリとウィジェットの色が染まる

「今ある無料の機能はこれからも無料」は、掲載文の説明文と同じく、ここでも書きました。価格の数字は書きません（国で変わるため）。
Plus の機能・ボタンの名前はアプリの訳（`Localizable.xcstrings`）、言葉の選び方は掲載文（[metadata/](../metadata/)）にそろえています（推し: zh-Hans 本命・zh-Hant 我推・ko 최애・th โอชิ・ほかは oshi）。
en-GB は en を英国のつづり（colour）に、es-MX は es と同じ文面にしています（中南米でもそのまま通じる言い方のため）。
