# このバージョンの新機能（1.1.0）

App Store Connect の「このバージョンの新機能」に入れる文面です（4,000 文字まで）。
ワークフロー「App Store Metadata」が、登録するバージョン（既定は `MARKETING_VERSION`）と同じ名前のファイルを読みます。
見出し（`## <言語>`）はスクリプトが探すので変えません。各見出しの下の最初のコードブロックが登録される文面です。

1.0.0 からの変更は次の 2 つです。

- デザインの一新: 地雷系・ゴシックのテーマ（Issue #114・Discussion #80）とナビゲーションバーのタイトルの書体（Discussion #148）。
  書体（Kaisei Decol）が変わるのは日本語だけなので、書体のことは ja だけに書きました。
  装飾は十字とハートですが、文面ではハートだけにしました（十字は宗教の印と受け取られることがあるため）
- 推しの写真の調整: 写真を選ぶと調整画面が開き、丸い枠に写す範囲を決められます（Discussion #128。[photo-crop.md](../../photo-crop.md)）。
  登録済みの写真も「位置を調整」で調整できます。ボタンの名前はアプリの訳（`Localizable.xcstrings`）にそろえました

言葉の選び方は掲載文（[metadata/](../metadata/)）にそろえています（推し: zh-Hans 本命・zh-Hant 我推・ko 최애・th โอชิ・ほかは oshi）。
