# App Store の掲載文（下書き）

文字数の上限は App Store Connect の制限（アプリ名 30 文字、サブタイトル 30 文字、プロモーションテキスト 170 文字、キーワード 100 文字、説明文 4,000 文字）。

## アプリ名（候補・人間が決める）

アプリ名は App Store 全体で重複できないため、App Store Connect で空いているかを確かめて決める。

1. 推し活カウントダウン
2. 推し活カウントダウン - 推しの予定まであと何日
3. 推し活カウント

ホーム画面の表示名（`CFBundleDisplayName`）は「推し活カウント」（判断ログ #9 の仮決め）。

## サブタイトル（30 文字まで）

```
推しのライブ・誕生日まであと何日？
```

## プロモーションテキスト（170 文字まで）

```
推しのライブ、誕生日、発売日、配信。楽しみな日を登録すると「あと何日」をひと目で数えます。推し色で彩られたカウントダウンを、ホーム画面のウィジェットにも。データは外部に送信しません。
```

## 説明文（4,000 文字まで）

```
推しのライブ・誕生日・発売日・配信など、楽しみな予定を登録して「その日まであと何日」を数える、推し活のためのカウントダウンアプリです。

■ 推し色のカウントダウン
推しの名前と推し色（メンバーカラー）を登録すると、予定やカウントダウンが推し色になります。推しの写真をアバターにすることもできます。

■ いちばん近い予定がひと目でわかる
ホームの先頭に、いちばん近い予定を大きく表示します。いちばん大事な予定を 1 件ピン留めしておけます。推しごとの絞り込みもできます。

■ 秒まで数える詳細画面
予定を開くと、開演（開始）までの日数と時・分・秒が 1 秒ごとに進みます。登録した日から当日までの進み具合もバーでわかります。

■ 毎年くり返す予定
誕生日や記念日は「毎年くり返す」にしておくと、過ぎたら翌年の同じ日を数えます。2 月 29 日の予定は、平年は 2 月 28 日に数えます。

■ ホーム画面ウィジェット
・カウントダウン：選んだ予定 1 件の「あと何日」
・推しカウント：これからの予定を近い順に一覧
ウィジェットから予定の詳細や予定の追加を開けます。

■ iPhone と iPad に対応
iPad の大きな画面や横向きでも使えます。ダークモードにも対応しています。

■ データは端末の中だけ
推し・写真・予定は端末の中だけに保存し、外部に送信しません。アカウントの登録も不要です。
（端末のバックアップ（iCloud・パソコン）には含まれます。アプリを削除すると消えます。）

予定の種類：ライブ・誕生日・発売日・配信・その他
```

## キーワード（100 文字まで・カンマ区切り）

アプリ名とサブタイトルに入っている語は、キーワードに入れなくても検索の対象になる。アプリ名が決まったら、重なる語（推し活・カウントダウン・推し・ライブ・誕生日など）を外して、別の語（何日後・カウント・イベント・予定 など）に回す。

```
推し活,カウントダウン,推し,ライブ,誕生日,発売日,配信,記念日,残り日数,推し色,メンバーカラー,ウィジェット,オタク,遠征,参戦
```

（67 文字）
