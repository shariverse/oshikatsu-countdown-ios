# iOS 版だけの決定

## 対象

- iPhone と iPad。iOS 17.0 以上
- 広い画面・横向きでも崩れないこと。文字の太さ・色は、ダイナミックタイプとダークの外観で崩れないこと

## 見た目

- 部品と操作感は SwiftUI の標準とデザインキャンバスに従う
- 配色・書体・角の丸み・装飾は、出荷するテーマ[地雷系・ゴシック](design/jirai-gothic.md)に従う。デザインの無い画面は主要画面の雰囲気に合わせる
- 予定の種類は、横に並べた選択肢から選ぶ。とても大きな文字の設定では収まらないので、メニューから選ぶ
- 推し色の選択は、色の丸を並べる。読み上げでは、色の名前・何個目か（「12 個中 3 個目」）・選んでいるかを伝える

## 失敗の出し方

- 保存・削除の失敗は、アラートで出す（ボタンは「閉じる」）
- 保存したデータを開けなかったときは、タブの代わりに「データを開けませんでした」「アプリを終了して、もう一度開いてください。端末の空き容量が少ないときは、空きを増やしてからお試しください。」を出す

## バックアップ

推し・写真・予定は、端末のバックアップ（iCloud・パソコン）に含まれる。アプリを削除すると消える。

## 言語

12 言語（英語が既定。ほかに日本語・簡体字中国語・繁体字中国語・韓国語・フランス語・ドイツ語・スペイン語・ブラジルのポルトガル語・イタリア語・タイ語・インドネシア語）。対応していない言語の端末では英語で出す。

- 日付・時刻・日数の書き方も、アプリが出している言語にそろえる（英語は `Sun, Oct 18, 2026`・`3 days left`。タイ語の日付は仏暦）。地域は端末の設定のまま
- ホームの先頭の予定のカードの日付は、日を先に書く言語では `18.10 SUN` にする（曜日はどの言語でも英語の大文字）
- 用語は App Store の掲載文にそろえる（推し: 簡体字中国語は「本命」、繁体字中国語は「我推」、韓国語は「최애」、タイ語は「โอชิ」、ほかは「oshi」）
- アプリの名前は、App Store の名前のコロンより前の部分。ホームの画面の名前（読み上げ）・[シェア](features/13-share.md)の透かし・課金画面の題（後ろに「Plus」を付ける）に使う
