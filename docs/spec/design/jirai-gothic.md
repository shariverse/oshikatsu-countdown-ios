# 地雷系・ゴシック

iOS 版の出荷するテーマ。デザインキャンバスの配色・書体・角の丸み・装飾をこのテーマで置き換えた。設定でテーマを選ぶ仕組みは無い。

変えるのは見た目（地の配色・書体・角の丸み・装飾）だけで、機能・文言・規則は変えない。[推し色](oshi-colors.md)の値と役割もそのまま。

## 狙い

黒 × ピンクで、ダークが主役。ライトも薄いピンクの地に黒の文字・黒の縁取りで、世界観が分かるようにする。日本語の本文は装飾的な明朝で、ゴシックの雰囲気を出す。

## 配色

役割の名前はデザインキャンバスの配色と同じ（このテーマには outline が無い）。

| 役割 | ライト | ダーク |
|---|---|---|
| background（画面の地） | `#FFF0F5` | `#120D12` |
| surface（カード・シート） | `#FFFFFF` | `#1E141C` |
| surfaceContainer（入力欄の地） | `#FBE4EE` | `#180F16` |
| surfaceContainerHigh（進み具合のバーの溝・区切り） | `#F0C9DA` | `#3A2533` |
| onSurface（本文） | `#1A0F16` | `#F6E6EE` |
| onSurfaceVariant（補助テキスト） | `#5A3A4C` | `#D6B9C8` |
| outlineVariant（区切り線） | `#E8B9CF` | `#5C3A4E` |
| brand / onBrand | `#C2185B` / `#FFFFFF` | `#FF7EB3` / `#3A0A20` |
| brandContainer / onBrandContainer（選択中の印の地と、その上の文字） | `#F8C8DC` / `#1A0F16` | `#6E1E45` / `#FFD9E8` |

## 推し色の文字のコントラスト

ライトの地が薄いピンクなので、推し色の文字を黒に寄せて 4.5:1 を保つ（寄せる割合は[推し色](oshi-colors.md#地の上の文字に使うとき)。ダークは白に 45% 寄せる）。
推し色 12 色の文字は、画面の地・カードの地・入力欄の地のどれに置いても 4.5:1 以上にする。[テーマカラー](#テーマカラー)でどの推し色に染めたときも同じ（測った値は[コントラストの補足](https://github.com/shariverse/app-specs/blob/2a37347c023304b7bac2fbab1ea34435ae775f37/oshikatsu-countdown/notes/jirai-gothic-contrast.md)）。

本文と補助テキストは、模様を重ねた地でも 4.5:1 以上にする。

## 書体

- 日本語の本文: Kaisei Decol（Regular / Bold。Medium は Regular に寄せ、合成の太字にしない）。SIL Open Font License 1.1（[google/fonts](https://github.com/google/fonts) の `ofl/kaiseidecol`）
- 数字: Outfit の Heavy（デザインキャンバスでは Bold）。桁の幅をそろえる（秒が進んでも横に揺れない）
- 日本語のときだけ Kaisei Decol を使い、ほかの言語はシステムの書体（中国語・韓国語・タイ語の字形が無いため）。数字の Outfit はどの言語でも使う
- ナビゲーションバーのタイトルも、日本語のときだけ Kaisei Decol の太字。大きさは OS の標準のタイトルにそろえ（大きいタイトルは端末の文字の大きさの設定に合わせて大きくし、小さいタイトルは大きくしない）、装飾は付けない。バーのボタン・戻るボタン・タブバーの文字はシステムの書体

## 角の丸み

| 部品 | このテーマ | デザインキャンバス |
|---|---|---|
| ホームの先頭の予定のカード | 16 | 28 |
| 見出しつきのまとまり（これからの予定など） | 12 | 20 |

単位は iOS の pt。

## 装飾

- 画面の地: ホーム・課金画面・シェアのカードは、十字とハートを小さく散らす（不透明度 0.35）。同じ大きさの模様をくり返して敷くので、広い画面でも模様の密度は変わらない。推しの一覧・設定・予定と推しの編集・初回の導線・シェアのプレビューの地は background の単色
- カードの縁: 二重の線（外側に 1.5、その 4 内側に 1。内側の線は不透明度 0.5。単位は iOS の pt）。ホームの先頭の予定のカード・見出しつきのまとまり・課金画面の機能の一覧・シェアのカードに付ける
- 見出しの前にハートを置く
- 写真が無いときの写真の場所: 推し色の斜めの縞の代わりに、推し色を黒に 30% 寄せた地に、白い十字とハート（不透明度 0.2）を互い違いに散らす
- 設定・予定と推しの編集・ライセンスの一覧の行の地も、カードの地（surface）にそろえる
- 装飾は図形と記号で描き、画像の素材は使わない。読み上げ・押せる範囲・並び順を変えず、カードの中の文字の上には重ねない
- ホーム画面ウィジェットの地: カウントダウンは推し色の塗り、予定を出せないときの案内はカードの地（surface）、推しカウントは入力欄の地（surfaceContainer）。推しカウントの ＋ は brand の丸に onBrand の記号
- ホーム画面ウィジェットに効くのは配色と書体で、地の模様・二重の線・見出しのハートは入れない。[推しの写真ウィジェット](../features/16-photo-widget.md)の写真が無いときは、上の「写真が無いときの写真の場所」の模様を使う

## テーマカラー

テーマのピンクを、1 位の推し（[推しの並べ替え](../features/15-oshi-order.md)）の推し色で染める。「黒 × ピンク」が「黒 × 1 位の推しの推し色」になる。無料の機能。

| 項目 | 規則 |
|---|---|
| 染めるもの | 上の配色のうち、削除の文字（destructive）を除くすべてと、装飾の色（十字とハート・二重の線・見出しのハート）。地・アクセント・区切り線のピンクが置き換わり、本文と補助テキストはわずかな色みだけ変わる。ライトの surface の白のように、ピンクを含まない色は変わらない |
| 変えないもの | 削除の文字、[推し色](oshi-colors.md)の値と役割、推し色の文字を寄せる割合、書体、角の丸み、装飾の形 |
| 染めないとき | 推しがいないとき・1 位の推しがピンクのときは、上の配色のまま |
| 効く場所 | アプリの画面とホーム画面ウィジェット。ロック画面のカウントダウン・ライブアクティビティ・[シェア](../features/13-share.md)のカードは変わらない |
| 染め直すとき | 推しの並べ替え・推し色の変更・推しの削除のあと、すぐ染め直す（ウィジェットも描き直す） |
| 染め方 | 色ごとに、基準のピンク（推し色のピンク `#C8326A`）をどれだけ含むかを求め、その分だけ 1 位の推しの推し色との差を足す。含む割合は、その色の R・G・B を基準のピンクの R・G・B に直線で当てはめたときの傾き（白・黒・灰色は 0、ピンクそのものは 1）。各チャンネルは 0〜1 に収める |

染めた色の目安は[コントラストの補足](https://github.com/shariverse/app-specs/blob/2a37347c023304b7bac2fbab1ea34435ae775f37/oshikatsu-countdown/notes/jirai-gothic-contrast.md)。
