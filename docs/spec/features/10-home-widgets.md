# ホーム画面ウィジェット

端末のウィジェットの一覧から置く。色は端末の外観（ライト / ダーク）に合わせる。
カウントダウンと推しカウントは無料。推しの写真を背景にするものは、Plus の[推しの写真ウィジェット](16-photo-widget.md)。

## カウントダウン

選んだ予定 1 件。推し色の塗りに白い文字で、推しの名前（推しなしの予定は種類）、タイトル、「あと N 日」。
当日は「今日！」、終わった予定は「N 日前」。数字は桁が多い・ウィジェットが狭いときに小さくする。

- 一覧に出す名前は「カウントダウン」、説明は「選んだ予定まであと何日かを推し色で表示します」
- 表示する予定は、当日とこれからの予定（近い順）から 1 件選ぶ。選ぶ一覧の行は、タイトルと「日付 · 推しの名前」（`10月18日(日) · ミナト`。毎年くり返す予定は次の回の日付。推しなしの予定は「推しなし」）
- 選んだあとに終わった予定は、選び直すまで「N 日前」と出し続ける
- 押すとアプリで予定の詳細を開く
- 読み上げは「推しの名前、タイトル、あと N 日」

大きさは小（2×2）。予定はウィジェットの編集で選ぶ。置いたばかりのときは、予定を選んでいない。
予定を出せないときは、推し色の塗りの代わりにカードの地に次の文言を出す。押すとアプリを開く（ホームのタブに切り替えるだけ）。

| 状態 | 見出し | 補足 |
|---|---|---|
| 予定を選んでいない | 「予定を選んでください」 | 「長押しして「ウィジェットを編集」から選びます」 |
| 選んだ予定が削除された | 「予定が見つかりません」 | 「長押しして「ウィジェットを編集」から選び直します」 |
| データを読み込めない | 「データを読み込めませんでした」 | 「しばらくしてからもう一度表示します」 |

データを読み込めないとき（データの形が変わる更新のあと、アプリをまだ開いていないときなど）は、「予定が見つかりません」とは分けて出し、15 分後に読み直す。

## 推しカウント

当日とこれからの予定を近い順に、推し色の丸・タイトル・残り日数（推し色）。見出しは「推しカウント」。予定が無ければ「これからの予定はありません」。

- 一覧に出す名前は「推しカウント」、説明は「これからの予定を近い順に表示します」
- 残り日数は「3日」のように短く出す（当日は「今日！」）。行に推しの名前は出さない
- 行を押すとアプリで予定の詳細、右上の ＋（読み上げは「予定を追加」）で予定の追加、見出しでアプリを開く
- 大きさは中（4×2）。近い順に 4 件まで出し、文字が大きいなどで収まらなければ、収まる件数まで減らす（スクロールしない）
- 行の読み上げは「タイトル、あと 3 日」。＋ は見た目の丸（32pt）より広い範囲（44pt）を押せる。行・＋ のほかの場所を押しても、アプリを開く
- データを読み込めないときは、一覧の代わりに「データを読み込めませんでした」を出し、15 分後に読み直す

## 共通

- アプリで開く画面は[規則](../rules.md)の「アプリで開く画面」のとおり
- 推しなしの予定は、[規則](../rules.md)の「推しなしの予定の色」で描く
- 推し・予定を保存・削除したら、すぐ描き直す
- 端末のタイムゾーンで日付が変わる時刻（0:00）に数え直す。端末の時刻・タイムゾーンを変えたときと、アプリが前面に来たときにも描き直す
- カウントダウンと推しカウントには写真を出さない（写真を出すのは推しの写真ウィジェットだけ）
- テーマの配色と書体は効かせるが、装飾は入れない。配色はアプリと同じく、1 位の推しの推し色で染める（[地雷系・ゴシック](../design/jirai-gothic.md)）
- ホーム画面を色合い付き・透明にしているとき（iOS 18 以降。端末がウィジェットを 1 色で描く）は、推しカウントの ＋ を輪郭の丸にする

ロック画面に置く形は[ロック画面のカウントダウン](11-lock-screen.md)。
