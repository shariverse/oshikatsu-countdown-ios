# 当日のライブアクティビティ

開始の時刻がある予定の当日に、開始までのカウントダウンを端末の常に見える場所に出す。通信もプッシュも使わない。

iOS ではロック画面と Dynamic Island に出す。

## 出す予定と時間

- 出す予定: 開始の時刻がある予定だけ。時刻の無い予定（誕生日など）には出さない
- 出す時間: 開始の 3 時間前から、開始の 1 時間後まで。同じ時間帯に複数あれば、それぞれ出す

## 中身

- 推し色の塗りに白い文字（カウントダウンのウィジェットと同じ）。推しの名前（推しなしの予定は種類）・タイトル・開始の時刻（`開演 17:00`）と、残りの見出し（`開演まで`）と時:分:秒（1 秒ごとに進む）。開始を過ぎたら「今日は当日！」
- 押すと、アプリでその予定の詳細を開く（[規則](../rules.md)の「アプリで開く画面」）

- Dynamic Island: 小さい表示はハートと残り、広げると推しの名前・残り・タイトル・開始の時刻。縁は推し色
- 始め方: iOS 26 以降は開始の 3 時間前に始まるよう予約し、始まるときに予定の名前と開始の時刻を音付きで知らせる。
  iOS 17・18 は予約できないので、開始の 3 時間前を過ぎてアプリを開いたとき（開演 1 時間前の通知を押したときを含む）に始める

## 規則

| 項目 | 規則 |
|---|---|
| 時間帯 | 開始の時刻（書いた日付・時刻を端末のタイムゾーンで読む）の 3 時間前から 1 時間後まで。毎年くり返す予定はその回の日付で数え、夜遅くの開始で時間帯が日付をまたいでも、前の回の時間帯を出し続ける |
| 予約 | これから時間帯が始まる予定を、8 日先までの近い順に 3 件まで予約する（iOS 26 以降） |
| 置き直し | 推し・予定を保存・削除したとき、日付・時刻・タイムゾーンが変わったとき、アプリが前面に来たときに置き直す。削除した・時刻を変えた・時間帯を過ぎた予定のものと、中身（タイトル・推しなど）が変わったものは終える |
| 終え方 | 開始の 1 時間後に終えるのはアプリを開いたときで、開かなければ iOS が 8 時間で終える |
