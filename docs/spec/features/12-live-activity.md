# 当日のライブアクティビティ

開始の時刻がある予定の当日に、開始までのカウントダウンを端末の常に見える場所に出す。通信もプッシュも使わない。

iOS ではロック画面と Dynamic Island に出す。

## 出す予定と時間

- 出す予定: 開始の時刻がある予定だけ。時刻の無い予定（誕生日など）には出さない
- 出す時間: 開始の 3 時間前から、開始の 1 時間後まで。同じ時間帯に複数あれば、それぞれ出す

## 中身

- 推し色の塗りに白い文字（カウントダウンのウィジェットと同じ）。推しの名前（推しなしの予定は種類）・タイトル・開始の時刻（`開演 17:00`）と、残りの見出し（`開演まで`）と時:分:秒（1 秒ごとに進む。残りが 1 時間を切ったら `59:59` のように分:秒）。呼び名は種類で変わる（[規則](../rules.md)の「開始の時刻の呼び名」）
- 開始の時刻になったら、残りの見出しと時:分:秒の代わりに「今日は当日！」を出す（アプリを開かなくても替わる）
- 押すと、アプリでその予定の詳細を開く（[規則](../rules.md)の「アプリで開く画面」）

- ロック画面: 左に推しの名前・タイトル（2 行まで）・開始の時刻、右に残りの見出しと時:分:秒。書体はテーマのもの（テーマの配色と装飾は使わない）
- Dynamic Island（縁は推し色。書体はシステムのもの）
  - 小さい表示: 左にハート、右に残りの時:分:秒（開始を過ぎたら「今日は当日！」）
  - 最小の表示（ほかのアプリの表示と並ぶとき）: ハートだけ
  - 広げた表示: 左上にハートと推しの名前、右上に残りの見出しと時:分:秒（開始を過ぎたら「今日は当日！」）、下にタイトルと開始の時刻
  - 読み上げ: 小さい表示のハートは推しの名前、最小の表示のハートはタイトル
- 始め方: iOS 26 以降は開始の 3 時間前に始まるよう予約し、始まるときに予定の名前と開始の時刻を音付きで知らせる。
  iOS 17・18 は予約できないので、開始の 3 時間前を過ぎてアプリを開いたとき（開演 1 時間前の通知を押したときを含む）に始める。
  iOS 26 以降でも、時間帯に入っているのにまだ出ていない予定は、置き直しのときにその場で始める
- 端末の設定でこのアプリのライブアクティビティを切っているときは、始めない・予約しない（出ているものを終えることはする）。アプリの設定に切り替えは置かない

## 規則

| 項目 | 規則 |
|---|---|
| 時間帯 | 開始の時刻（書いた日付・時刻を端末のタイムゾーンで読む）の 3 時間前（ちょうどを含む）から 1 時間後（ちょうどは含まない）まで。開始が 0 時台なら前の日の夜から出す。毎年くり返す予定はその回の日付で数え、夜遅くの開始で時間帯が日付をまたいでも、前の回の時間帯を出し続ける |
| 予約 | これから時間帯が始まる予定を、8 日先までの近い順に 3 件まで予約する（iOS 26 以降） |
| 置き直し | 推し・予定を保存・削除したとき、日付・時刻・タイムゾーンが変わったとき、アプリが前面に来たときに置き直す。削除した・時刻を変えた・時間帯を過ぎた予定のものは終える。中身（タイトル・推しなど）が変わったものは、終えてから新しい中身で出し直す（中身が同じなら出し直さない） |
| 終え方 | 開始の 1 時間後に終えるのは置き直しのとき（アプリを開いたときなど）で、終えたものはすぐに消す。開かなければ iOS が 8 時間で終える |
